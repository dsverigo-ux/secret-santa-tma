# Сервер «Тайного Санты» (Cloudflare Worker + D1)

Один файл `worker.js`: хранит участников, проверяет вход из Telegram,
даёт организатору одобрять заявки и проводить жеребьёвку, бот пишет участникам.

## Установка (один раз, ~15 минут, удобнее с компьютера)

1. Зарегистрироваться на https://dash.cloudflare.com (бесплатно, карта не нужна).
2. **Storage & Databases → D1 SQL Database → Create** — имя `santa`.
3. **Workers & Pages → Create → Worker → Start with Hello World** — имя `secret-santa` → **Deploy**.
4. **Edit code** → удалить всё → вставить содержимое `server/worker.js`
   (https://raw.githubusercontent.com/dsverigo-ux/secret-santa-tma/main/server/worker.js) → **Deploy**.
5. Воркер → **Settings → Bindings → Add → D1 database**: имя переменной `DB`, база `santa`.
6. Воркер → **Settings → Variables and Secrets → Add**:
   - `BOT_TOKEN` — тип **Secret**, значение — токен бота из @BotFather.
7. Открыть в браузере `https://secret-santa.<ваш-поддомен>.workers.dev/setup` — должно быть `"ok": true`.
8. Написать боту `/myid` → он пришлёт ваш Telegram ID.
   Добавить переменную `ADMIN_IDS` (тип Text) = этот ID (несколько — через запятую) → **Deploy**.
9. Адрес воркера вписать в `js/data.js` → `api: "https://secret-santa.<поддомен>.workers.dev"`.

## Как идёт игра
- Коллега открывает приложение → пишет имя, отдел, пожелания → заявка уходит организатору (бот присылает уведомление).
- Организатор: кнопка **«Панель организатора»** внизу любого экрана → «Одобрить» / «Отклонить» / «Одобрить всех».
- В день жеребьёвки организатор нажимает **«Провести жеребьёвку»** → пары по кругу (никто не вытянет себя) → бот пишет каждому.
- Участник открывает игру → «растапливает лёд» → видит имя и пожелания коллеги → отмечает «Подарок куплен».

Демо-режим: в браузере или по ссылке с `?demo`.
