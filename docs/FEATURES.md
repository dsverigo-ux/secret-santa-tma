# Тайный Санта — Telegram Mini App: функционал

## 1. Роли
| Роль | Возможности |
|---|---|
| **Организатор** | создаёт игру, задаёт бюджет и даты, приглашает участников, настраивает исключения, проводит жеребьёвку, видит статусы (без раскрытия пар) |
| **Участник** | вступает по ссылке, заполняет вишлист, после жеребьёвки видит подопечного, задаёт анонимные вопросы, отмечает «подарок отправлен/получен» |

## 2. Пользовательские сценарии

### 2.1 Создание игры
- Название, описание/правила, эмодзи-обложка
- Бюджет (сумма + валюта, «до N ₽»)
- Дата жеребьёвки (дедлайн регистрации) и дата обмена подарками
- Формат: офлайн-встреча / доставка по адресу
- Настройки: анонимный чат с подопечным, обязательный вишлист, участвует ли организатор

### 2.2 Приглашение
- Ссылка вида `https://t.me/<bot>/<app>?startapp=g_<код>` — открывает Mini App сразу на экране вступления (параметр читается из `initDataUnsafe.start_param`)
- Кнопка «Поделиться» → `Telegram.WebApp.openTelegramLink('https://t.me/share/url?url=…')` или `switchInlineQuery`
- Код игры для ручного ввода
- Добавление в групповой чат: бот публикует карточку игры с кнопкой

### 2.3 Вступление
- Экран-приглашение: название, организатор, бюджет, даты, кол-во участников
- Профиль подтягивается из Telegram (`initDataUnsafe.user`: имя, фото) — регистрация не нужна
- Сразу после вступления — предложение заполнить вишлист

### 2.4 Вишлист
- Список желаний (текст + опциональная ссылка)
- «Чего не дарить» (аллергии, не люблю…)
- Размеры / предпочтения, подсказки для Санты
- Адрес доставки (видит только свой Санта, только после жеребьёвки)

### 2.5 Исключения (организатор)
- Пары, которые не могут выпасть друг другу (супруги, коллеги из одного отдела)
- Проверка на выполнимость жеребьёвки

### 2.6 Жеребьёвка
- Запускает организатор (или автоматически по дате)
- Алгоритм — случайный цикл (derangement) с учётом исключений, на сервере
- Каждый участник получает push от бота: «Жеребьёвка прошла, открой, чтобы узнать подопечного»
- Анимированное раскрытие карточки подопечного

### 2.7 После жеребьёвки
- Карточка подопечного + его вишлист
- Анонимные вопросы подопечному («Санта спрашивает…»), ответы приходят Санте; переписка через бота
- Статусы: «Подарок куплен» → «Отправлен» → подопечный отмечает «Получен»
- Организатор видит прогресс (сколько купили/отправили), но не пары
- Напоминания от бота: заполнить вишлист, до обмена N дней

### 2.8 Финал
- Раскрытие Сант (опционально, по решению организатора)
- «Спасибо Санте» — анонимная благодарность

## 3. Интеграция с Telegram WebApp API
| API | Где используется |
|---|---|
| `ready()`, `expand()` | инициализация |
| `themeParams` / CSS-переменные `--tg-theme-*` | светлая/тёмная тема под клиент |
| `MainButton` | основное действие экрана (Создать, Сохранить, Провести жеребьёвку) |
| `BackButton` | навигация назад |
| `HapticFeedback` | тактильный отклик при жеребьёвке и действиях |
| `showConfirm` / `showPopup` | подтверждение жеребьёвки, выхода из игры |
| `initData` | авторизация: сервер проверяет подпись HMAC-SHA256 токеном бота |
| `start_param` | вступление по ссылке |
| `openTelegramLink` | шаринг приглашения |
| `CloudStorage` | черновики вишлиста |
| `contentSafeAreaInset` | отступы в fullscreen |

## 4. Экраны (реализованы в верстке)
1. Главная — мои игры, создать, вступить по коду
2. Создание игры
3. Приглашение (вступление по ссылке)
4. Игра — до жеребьёвки (участники, ссылка, мой вишлист, админ-действия)
5. Мой вишлист
6. Исключения
7. Жеребьёвка — анимация раскрытия
8. Подопечный — вишлист, статус подарка
9. Анонимный чат с подопечным

## 5. Бэкенд (следующий этап)
- Бот (aiogram / grammY) + REST API
- БД: users, games, participants, wishlist_items, exclusions, assignments, messages
- Проверка `initData` на каждом запросе
- Хостинг фронта: GitHub Pages / Vercel (нужен HTTPS)
