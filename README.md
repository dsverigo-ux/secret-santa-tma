# 🎅 Тайный Санта — Telegram Mini App

Верстка мини-приложения для игры «Тайный Санта» внутри Telegram: создание игры, приглашение по ссылке, вишлисты, исключения, жеребьёвка, анонимный чат с подопечным.

Сейчас это **фронтенд на демо-данных** (без бэкенда) — его можно открыть в браузере или подключить к боту для просмотра в Telegram.

## Как устроено
Одна игра — «Новый год Р-СТРОЙ». Путь простой и линейный, без возврата назад — чтобы было понятно любому сотруднику:

1. **Привет и правила** — «Какие правила?», «Твои возможности», кнопка «Поехали!»
2. **Пожелания** (шаг 1 из 3) — что хочу получить и чего не дарить, кнопка «Следующий шаг»
3. **Ожидание** (шаг 2 из 3) — «Отлично! Ты всё сделал(а) правильно!», дата жеребьёвки, памятка
4. **Жеребьёвка** (шаг 3 из 3) — подарок «приезжает по трубе», кнопка «Узнать, кому я дарю»
5. **Подопечный** — «Время выбирать подарок!», его пожелания, кнопка «Подарок куплен!»
6. **Готово** — напоминание о вручении

Крупный текст, одна большая кнопка на экране, прогресс сохраняется между запусками.
Параметры игры (даты, бюджет, место) — в `js/data.js`.
Для просмотра: `?step=welcome | wishlist | waiting | reveal | recipient | done`, сброс прогресса — `?reset`.

Полное описание функционала: [docs/FEATURES.md](docs/FEATURES.md)

## Дизайн
Основная тема — **«Морозное утро»** в фирменном стиле Р-СТРОЙ:
- светлый морозно-голубой фон, белые карточки, падающий снег;
- палитра бренда — тёмно-синий `#1f2f5c`, красный `#b3261e` — плюс «шампань» `#ecd9a8` (перекликается с жёлтой окраской газопроводов);
- фирменные приёмы: красный диагональный уголок, заголовки секций с красной чертой, плитки «как в оффере»;
- иллюстрации в газовой тематике: ночной промысел — факельная башня-ёлка с пламенем вместо звезды, шаровые газгольдеры, колонны и эстакада с гирляндой; на жеребьёвке открывается задвижка и подарок «поступает по магистрали»;
- шрифты: Unbounded (заголовки), Manrope (текст), Cormorant Garamond (акценты).

Запасные варианты включаются параметром адреса: `?theme=classic` (ночной синий), `aurora` («Северное сияние»), `dusk` («Зимние сумерки»), `retro` («Советская открытка»), `neon` («Огни промысла»), `velvet` («Ёлочный бархат»), `minimal` («Минимал»), `cozy` («Один на объекте», с котом-прорабом), `crystal` («Кристалл» — перелив и стеклянная снежинка).

## Стек
Чистые HTML + CSS + JS, без сборки. Подключён официальный SDK `telegram-web-app.js`:
- цвета берутся из темы Telegram (`--tg-theme-*`), есть фолбэк для браузера, включая тёмную тему;
- `MainButton` / `BackButton` — нативные кнопки; вне Telegram показываются HTML-заменители;
- `HapticFeedback`, `showConfirm`, `openTelegramLink`, `CloudStorage`, `start_param`.

## Структура
```
index.html
css/styles.css   — базовые стили
css/themes.css   — темы оформления
js/art.js       — иконки и иллюстрации (SVG)
js/art-themes.js — иллюстрации тем
js/data.js      — демо-данные
js/app.js       — пошаговый сценарий и интеграция с Telegram WebApp
docs/FEATURES.md
```

(основное приложение бота, кнопка меню «Тайный Санта» и `/newapp` настроены в @BotFather; обложка — `cover-640x360.png`).
